# 企业级飞书表设计规格 + 建表手册（click-by-click）· 枚举版

> 本手册对应「账号管理系统 + 报销主表升级」方案。您需要在**现有同一个多维表格 base**（就是现在报销单主表 tbl5Dz4SdKmmwgP5 所在的那个多维表格）里**新建 2 张表**：
>
> 1. **用户表**（账号系统用）
> 2. **报销单主表V2**（17 字段的企业级升级版，含完整枚举）
>
> 旧表 tbl5Dz4SdKmmwgP5 **保留不动**，历史演示数据继续可用，改 `.env` 即可切换新旧表。  
> 建表约需 10~15 分钟。建完把两张表的 table_id 填进 `.env`（table_id 在浏览器地址栏里，形如 `tblXXXXXXXX`）。

## 一、报销单主表V2（17 字段 + M9 追加 2 列，全字段企业标准）

| #  | 字段名    | 飞书字段类型 | **企业标准枚举 / 取值约束**                                                       | 配置要点                        |
| -- | ------ | ------ | ----------------------------------------------------------------------- | --------------------------- |

| 7  | 事由     | 多行文本   | 自由文本，**5–200 字**，必须描述真实业务用途（示例：`北京出差高铁票` / `Q3 客户招待餐费`）                 |                             |

### M9 追加列 click-by-click（已有表补 2 列，约 1 分钟）

1. 打开报销单主表 → 在最后一列（审批时间）右侧点表头 `+`。
2. 字段名填 `发票信息` → 类型选「文本」→ 确定。
3. 再点 `+` → 字段名填 `发票附件` → 类型选「**附件**」→ 确定。
4. 核对：字段名逐字一致（`发票信息` / `发票附件`，无多余空格），否则代码写入会被过滤或报错。

#### OCR 识别字段 → 表列映射

| OCR 识别项 | 去向 | 说明 |
| --- | --- | --- |
| 金额 | `金额` 列 | OCR 识别值预填草稿，用户确认后落库 |
| 开票日期 | `发票日期` 列 | 归一为 `YYYY/M/D` 写毫秒时间戳 |
| 票据 | `票据状态` 列 | 传了发票图即视为 `有票` |
| 类型建议 / 城市 | `报销类型` / `城市` 列 | 必须命中枚举白名单，OCR 给不出则留空追问用户 |
| 发票号码 + 销售方 | `发票信息` 列（新增） | `号码；销售方` 拼接文本 |
| 发票图片原件 | `发票附件` 列（新增） | 确认提交后自动上传，单据与原图直接关联（点开即看） |
| 申请人 / 部门 | **不由 OCR 填** | 申请人一律以登录身份为准（防冒充）；部门以用户对话口述为准（未说时提示补齐） |

### click-by-click 步骤

1. 打开多维表格（就是现在主表所在的那个 base）。
2. 左下角 `+ 新建数据表` → 重命名为 `报销单主表V2`。
3. 默认第一个字段（多行文本）双击改名：`申请人`（这是字段 2；字段 1 的「单号」放最前面，见下一步）。
4. 点表格左上角 `+`（在首列之前插入列）→ 选「自动编号」→ 字段名填 `单号` → 编号规则：自定义 → 前缀填 `BX-` → 位数选 6 → 确定。
5. 逐个加字段：点表头最右侧 `+` → 选类型（见上表「飞书字段类型」列）→ 填字段名 → 若是单选，在右侧面板「选项」里**逐个添加上面「企业标准枚举」列给出的全部选项值** → 确定。
   - 「金额」选数字类型后，右侧面板数字格式切「货币」，符号 `¥`。
   - 「发票日期 / 记录提交时间 / 审批时间」选日期后，右侧面板把「携带时间」开关**关掉**。
   - **部门 / 城市 / 报销类型 / 票据状态 / 合规结果 / 状态** 都是单选，选项值必须按上方字典逐字照搬。
6. 建完后核对：共 17 列，字段名与上表**完全一致**（代码按字段名精确写入，多一个空格都会写失败）；6 个单选字段的选项值也与字典一致。

## 四、常见坑

- **字段名必须逐字一致**：`报销类型`≠`报销 类型`，`密码哈希`≠`密码hash`。
- 单选字段的**选项值**也要逐字一致（如角色必须是 `员工/财务/管理员` 三个值；报销单主表的部门 11 个值必须与字典完全相同）。
- 自动编号字段代码**永远不会写**，它是飞书自动生成的。
- 日期字段写失败多半是「携带时间」开了（代码写的是纯日期毫秒时间戳，兼容两种，但建议关掉保持一致）。
- **部门 / 城市 / 报销类型 已升级为单选**：建表时务必把字典里的选项值全部加进去，漏选项会导致写入失败。
- **代码层已强校验**：`models/feishu.py` 的 `DEPT_WHITELIST`/`CITY_WHITELIST` 等即上方字典的唯一定义源；落库前 `validate_enum_fields` 会拦截任何非标准值（如「火星部」），飞书下拉 + 代码白名单双保险。新增/修改枚举请同步改 `feishu.py`，不要只在飞书侧改。
