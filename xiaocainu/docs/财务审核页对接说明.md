# 财务审核页对接说明（/finance）

本文说明**财务专属审核页**的落地方式：页面只连本网关，网关**直连飞书多维表格**读写单据。

> **2026-10-19 架构变更**：本页原设计为「经队友的 C# 安全审计主服务器（agent-safe-gate）中转」，
> 现按用户决策改为**直连飞书**。主服务器适配层（`api/backend_client.py`）已整体删除。
> **动作审计与版本回溯由安全审计服务侧按操作日志实现**（删除 = 删单代码，新增 = 加单代码，
> 按审计记录的字段参数重建；注意飞书单号是自动编号，重建后单号会变）。
> 本页**不提供回退入口**。

---

## 一、数据流（两跳）

```
财务浏览器 finance.html ──(xc_token 同源)──► FastAPI 网关 dispatch
        │ 认证墙 + 角色门（仅财务/管理员）
        ▼
models/feishu.py ──► 飞书多维表格 tbloZoAVg0GCDPsZ（M3 那套凭证）
```

配置来源：`.env` 的 `FEISHU_APP_ID` / `FEISHU_APP_SECRET` / `FEISHU_APP_TOKEN` /
`FEISHU_TABLE_ID`。**无任何中转层配置项。**

## 二、角色与落地

| 角色 | 登录后落地 | 说明 |
| --- | --- | --- |
| 员工 | 聊天页 `/` | 误输 `/finance` 进入拒绝视图 |
| 财务 | `/finance` | 查 / 审 / 改 / **删**（用户 2026-10-19 拍板：财务亦可删） |
| 管理员 | `/finance` | 同财务 |

防循环跳转：聊天页对已登录财务/管理员自动跳 `/finance`；审核页回聊天页时置
`xc_from_finance` 标志，聊天页据此不跳回。

## 三、页面功能与能力位

`POST /finance/meta` 返回能力位与**表内真实枚举**（现场 `list_fields` 探测，失败回落内置常量）：

| 能力位 | 值 |
| --- | --- |
| `can_review` / `can_update` / `can_delete` | 财务与管理员均为 `true` |
| `can_rollback` | 恒为 `false`（回溯归审计侧） |

真实表结构（19 列，`list_fields` 实测）：单号(AutoNumber 只读) / 申请人 / 工号 / 部门 /
报销类型 / 金额 / 事由 / 票据状态 / 城市 / 发票日期 / 记录提交时间 / 合规结果 / 风险摘要 /
状态 / 审核人 / 审批意见 / 审批时间 / 发票信息 / 发票附件。

单选字段选项：部门 11 项、报销类型 4 项（差旅费/招待费/办公用品/交通费）、票据状态 3 项、
城市 37 项、合规结果 4 项、状态 4 项（待审核/审核中/已通过/已驳回）。

**财务可改字段白名单（9 项）**：部门 / 报销类型 / 金额 / 事由 / 票据状态 / 城市 / 发票日期 /
合规结果 / 风险摘要。写入前经 `validate_enum_fields`（枚举）+ `filter_by_schema`（缺列剔除）。

## 四、端点清单（POST + JSON，均在认证墙内）

| 端点 | 请求 | 说明 |
| --- | --- | --- |
| `GET /finance` | — | 页面免认证，数据端点全在墙后 |
| `POST /finance/meta` | `{}` | 能力位 + 枚举 + 可改字段 + 规则 |
| `POST /finance/list` | `{}` | 全部单据，按「记录提交时间」倒序，`page_size=500` |
| `POST /finance/detail` | `{record_id}` | 单条详情 |
| `POST /finance/review` | `{record_id,status,opinion}` | 状态限「已通过/已驳回」；意见 ≥2 字；写 状态+审核人+审批意见+审批时间 四字段；终态（已通过/已驳回）不可再审 |
| `POST /finance/update` | `{record_id,fields}` | 白名单 9 字段，键名为**中文列名** |
| `POST /finance/delete` | `{record_id,reason}` | 理由 ≥2 字；**物理删除不可恢复** |

> `POST /finance/rollback` 已随主服务器适配层一并移除。

## 五、错误口径

| 网关返回 | 含义 |
| --- | --- |
| 401 | 未登录或登录过期 → 清登录态回登录页 |
| 403 | 非财务/管理员角色 |
| 400 | 参数非法（状态值越界、意见过短、白名单外字段、枚举非法） |
| 404 | 单据不存在或已被删除 |
| 502 | 飞书 API 报错（`FeishuError`，含 code/msg 人类可读化） |
| 503 | 网关未接入飞书（缺 `FEISHU_APP_ID` / `FEISHU_TABLE_ID`） |

## 七、排障

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 列表空白 + 503 | 网关未接入飞书 | 检查 `.env` 的 `FEISHU_APP_ID` / `FEISHU_TABLE_ID` |
| 登录 401 | 口令错 | 用 `tools/user_admin.py list` 看账号；口令以你飞书用户表为准 |
| 筛选下拉是空的 | `list_fields` 探测失败 | 看网关日志 `[finance] 枚举探测失败`，会自动回落内置常量 |
| 审核报「当前状态为终态」 | 该单已通过/已驳回 | 终态不可再审，符合预期 |
| 修改报「不允许修改」 | 字段不在白名单 | 只有 9 个业务字段可改，申请人/状态等属盖章字段 |

## 八、已知边界

- **单号不可保持**：飞书单号是自动编号（type=1005），只读；审计侧按字段重建单据时单号会变。
- **无版本回溯**：修改与删除都不可逆，回溯由审计服务侧负责。
- **列表单页上限 500**：飞书 API 单页上限；当前表 11 条，远未触及。
- **历史脏数据**：表内 BX-000011 的「申请人」列填的是「北京」（疑似历史误填），非代码问题。
